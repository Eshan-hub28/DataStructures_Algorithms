# LeetCode 1002 - Find Common Characters

## Problem

Given an array of words, find all characters that appear in **every word**.

Example:

```
Input:
["bella","label","roller"]

Output:
["e","l","l"]
```

---

## Logic

This is a **Frequency Pattern** problem.

For multiple words:

```
Common frequency = Minimum frequency of a character in all words
```

Example:

```
Character: l

bella  -> 2 times
label  -> 2 times
roller -> 2 times

Minimum = 2

Answer:
l,l
```

---

## Step 1: Count First Word

Create a frequency array:

```java
int[] freq = new int[26];
```

Because there are only 26 lowercase letters.

Example:

```
bella
```

Frequency:

```
a -> 1
b -> 1
e -> 1
l -> 2
```

---

## Step 2: Compare Remaining Words

For every other word:

1. Count its frequency.
2. Compare with previous frequency.
3. Keep the minimum value.

Example:

```
Before:

l -> 2


Current word:

l -> 1


After Math.min():

l -> 1
```

Only characters present in all words will remain.

---

## Step 3: Create Answer

After comparing all words:

```
freq:

e -> 1
l -> 2
```

Now convert back to characters:

```
e
l
l
```

We use:

```java
while(freq[i] > 0)
```

because a character can appear multiple times.

Example:

```
l frequency = 2

Add l
Add l
```

---

## Important Syntax

### Character to index

```java
ch - 'a'
```

Example:

```
'a' -> 0
'b' -> 1
'l' -> 11
```

---

### Index to character

```java
(char)(i + 'a')
```

Example:

```
11 + 'a' = 'l'
```

---

## Code Flow

```
Words
 |
 |
Count first word
 |
 |
Compare every other word
 |
 |
Keep minimum frequency
 |
 |
Convert frequency to characters
 |
 |
Return answer
```

---

## Pattern 2 Reminder

```
One string:
    Count frequency

Two strings:
    Compare frequency

Multiple strings:
    Take minimum frequency
```

LeetCode 1002 is a **frequency + minimum comparison** problem.
