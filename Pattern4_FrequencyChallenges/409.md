LeetCode 409 - Longest Palindrome Explanation

Problem Idea

Given a string s, find the length of the longest palindrome that canbe built using the characters.

A palindrome is a string that reads the same forward and backward.

Examples:

aba
abba

The important observation:

Characters placed on the left side must have matching characters onthe right side.

Therefore, characters are needed in pairs.

One character with an odd frequency can be placed in the center.

Approach Used: Frequency Array

We use:

int[] freq = new int[128];

Why 128?

Because the problem can contain ASCII characters.

Each character has an ASCII value:

'a' -> 97
'A' -> 65
'!' -> 33

So we can directly use the character as an index.

Example:

freq[ch]++;

If:

ch = 'a'

then internally:

freq[97]++;

Step 1: Count Character Frequency

Code:

int[] freq = new int[128];

for(int i = 0; i < s.length(); i++){
    char ch = s.charAt(i);
    freq[ch]++;
}

Example:

Input:

s = "abccccdd"

Frequency:

a -> 1
b -> 1
c -> 4
d -> 2

Step 2: Use Character Pairs

Code:

for(int count : freq){

    length += (count / 2) * 2;

}

Why?

A palindrome needs matching pairs.

Examples:

Frequency = 4

aaaa

Use all 4:

(4/2)*2 = 4

Frequency = 5

aaaaa

Pairs:

aa aa a

Use:

4

Calculation:

(5/2)*2

= 2*2

= 4

One a can remain for the center.

Step 3: Handle Odd Frequency

Code:

if(count % 2 == 1){
    odd = true;
}

Example:

aaa

Frequency:

3

We can use:

aa

and keep:

a

for the middle.

Only one odd character can be placed in the center.

Example:

abcba

The middle character:

c

Complete Code

class Solution {
    public int longestPalindrome(String s) {

        int[] freq = new int[128];

        // Count frequency of each character
        for(int i = 0; i < s.length(); i++){
            char ch = s.charAt(i);
            freq[ch]++;
        }

        int length = 0;
        boolean odd = false;

        // Calculate palindrome length
        for(int count : freq){

            // Add available pairs
            length += (count / 2) * 2;

            // Check if a middle character exists
            if(count % 2 == 1){
                odd = true;
            }
        }

        // Add one character in the center
        if(odd){
            length++;
        }

        return length;
    }
}

Dry Run

Input:

s = "abccccdd"

Frequency:

a = 1
b = 1
c = 4
d = 2

Calculations:

a:
(1/2)*2 = 0

b:
(1/2)*2 = 0

c:
(4/2)*2 = 4

d:
(2/2)*2 = 2

Total:

0 + 0 + 4 + 2 = 6

Odd frequencies exist:

a or b

Add center:

6 + 1 = 7

Answer:

7

Pattern to Remember

For frequency problems:

Frequency is even:
Use everything

Frequency is odd:
Use frequency - 1
Keep one character for center

Formula:

length += (frequency / 2) * 2;

and:

if(frequency % 2 == 1)
    add one in the end

This frequency pattern is useful for: - Valid Anagram - Ransom Note -Longest Palindrome - Many string counting problems
