In LeetCode 692, we use it when two words have the same frequency.

Example:

word = "apple"
maxWord = "banana"

Now:

word.compareTo(maxWord)

means:

"apple".compareTo("banana")

Java compares character by character.

How comparison happens

ASCII values:

a = 97
b = 98

Compare:

apple
banana
 ^

First characters:

a vs b

Since:

a < b

Java returns a negative number.

Example:

"apple".compareTo("banana")

returns:

-1 (negative)

So:

word.compareTo(maxWord) < 0

becomes:

-1 < 0

true.

Meaning:

apple comes before banana
Another example
word = "cat"
maxWord = "apple"

Compare:

"cat".compareTo("apple")

First characters:

c vs a

Since:

c > a

Java returns positive:

2

Condition:

word.compareTo(maxWord) < 0

becomes:

2 < 0

false.

Meaning:

cat should not replace apple
If both words are same
"apple".compareTo("apple")

Result:

0

because they are equal.

Condition:

0 < 0

false.
