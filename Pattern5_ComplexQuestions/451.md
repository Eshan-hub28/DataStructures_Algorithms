Assume:

String s = "tree";

After frequency counting, our HashMap is:

map

Key      Value

't'       1
'r'       1
'e'       2

Remember:

Key   = character
Value = frequency
Step 1
List<Map.Entry<Character,Integer>> list =
        new ArrayList<>(map.entrySet());
What is map.entrySet()?

entrySet() gives all key-value pairs from the HashMap.

Before:

map

t -> 1
r -> 1
e -> 2

After:

map.entrySet()

(t,1)
(r,1)
(e,2)

Each pair is a Map.Entry.

A single entry contains:

entry.getKey()   -> character
entry.getValue() -> frequency

Now:

new ArrayList<>(map.entrySet())

creates a list containing these entries.

So:

list

index       Entry

0           (t,1)
1           (r,1)
2           (e,2)

Why convert to List?

Because:

HashMap cannot be sorted
ArrayList can be sorted
Step 2
Collections.sort(list, (a,b) ->
        b.getValue() - a.getValue()
);

This sorts the list based on frequency.

How comparator works

The lambda:

(a,b) -> b.getValue() - a.getValue()

means:

Take two entries:

a = first entry
b = second entry

Compare their values.

Comparison 1

Suppose:

a = (t,1)
b = (r,1)

Calculation:

b.getValue() - a.getValue()

becomes:

1 - 1

Result:

0

Means:

No change
Comparison 2

Suppose:

a = (t,1)
b = (e,2)

Calculation:

2 - 1

Result:

1

Positive means:

b should come before a

So:

(e,2)
(t,1)

After sorting:

list

index       Entry

0           (e,2)
1           (t,1)
2           (r,1)

Now highest frequency is first.
