5. Keep the smallest prefix sum
minSum = Math.min(minSum, sum);

This means:

"Between the smallest sum I've seen and the current sum, keep the smaller one."

Why do we need the smallest?

Because the starting value must be large enough to survive the worst/lowest point of the running sum.

6. Calculate the required starting value
return 1 - minSum;

The problem requires:

starting value + running sum >= 1

The worst case is minSum.

6. Why 1 - minSum?

This is the key mathematical idea.

The problem says:

The running value must always be at least 1.

We found:

minimum running sum = -4

Suppose starting value is 5.

Then the lowest point becomes:

5 + (-4)
= 1

Perfect.

Therefore:

starting value + minSum = 1

So:

starting value = 1 - minSum

Since:

minSum = -4

we get:

starting value = 1 - (-4)
               = 5
