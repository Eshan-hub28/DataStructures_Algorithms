LeetCode 1588 — Sum of All Odd Length Subarrays

Main Idea

Find all subarrays with odd length and add their sums.

Example:

nums = [1, 4, 2]

Odd-length subarrays:
[1]       -> 1
[4]       -> 4
[2]       -> 2
[1,4,2]   -> 7

Answer = 1 + 4 + 2 + 7 = 14

Prefix Sum

For:

nums   = [1, 4, 2]
prefix = [1, 5, 7]

Build it with:

int[] prefix = new int[n];

prefix[0] = arr[0];

for(int i = 1; i < n; i++) {
    prefix[i] = prefix[i - 1] + arr[i];
}

Getting a subarray sum

If left == 0:

sum = prefix[right];

Otherwise:

sum = prefix[right] - prefix[left - 1];

Example:

[4,2]

left = 1
right = 2

sum = prefix[2] - prefix[0]
    = 7 - 1
    = 6

///ver important where I make mistake
why prefix[left-1]
It should be:

sum = prefix[right] - prefix[left - 1];
Why?

Suppose:

nums = [1, 4, 2, 5]
prefix = [1, 5, 7, 12]

We want the subarray:

[4, 2]
 ↑     ↑
left  right
 1      2

Its sum should be:

4 + 2 = 6

Using your formula:

prefix[right] - prefix[left]
= prefix[2] - prefix[1]
= 7 - 5
= 2 ❌

We're accidentally removing 4 too.

The correct formula is:

prefix[right] - prefix[left - 1]
= prefix[2] - prefix[0]
= 7 - 1
= 6 ✅
